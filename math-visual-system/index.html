∫ Interactive Math Lab

数学可视化系统

一个纯前端 HTML 动态演示系统：支持自定义函数、常见函数、参数曲线、曲面热力图、二重积分黎曼和、三重积分切片体积、极坐标、向量场与多类型统计图。所有演示都用 Canvas 实时绘制，便于直接打开、教学展示和继续扩展。

8+可视化模块：函数、曲线、曲面、积分、极坐标、向量场、图表等。
2D/3D平面坐标、参数轨迹、曲面投影和体积切片动态呈现。
自定义可输入 x、t、x/y、x/y/z 的函数表达式并立即绘制。
过程二重积分、三重积分通过滑块展示分割逐步加密。

函数图像与常见函数库

输入任意关于 x 的表达式，或点击预设函数，系统会自动绘制坐标轴、网格、曲线并估计零点和区间面积。

函数设置

支持：sin、cos、tan、asin、acos、atan、sqrt、abs、log、exp、pow、min、max、PI、E。示例：sin(x) * exp(-0.1*abs(x))
-估计零点数量
-区间绝对面积
-采样值域

参数曲线动态轨迹

使用 x(t)、y(t) 绘制曲线，并通过进度滑块观察从 t 起点到终点的生成过程。

曲线设置

-估计弧长
-当前端点
800采样点

曲面 z = f(x,y)

左半区域显示热力等高效果，右半区域显示简化 3D 网格投影，适合观察曲面峰谷、鞍点与衰减。

曲面设置

-z 值范围
-平均高度
热力 + 投影展示模式

二重积分过程：∬R f(x,y) dA

将矩形区域 R 划分为 n×n 个小块，用每个小块中心点的函数值近似柱体高度，动态展示黎曼和逐步逼近。

积分设置

-黎曼和近似值
-小柱体数量
-单元面积 ΔA

三重积分过程：∭V ρ(x,y,z) dV

把空间盒子切成多个体素，根据密度函数为体素着色并分层投影，展示体积积分从切片到总体累积的过程。

体积积分设置

-体积积分近似值
-已显示体素
-单元体积 ΔV

极坐标曲线 r = f(θ)

展示玫瑰线、心形线、阿基米德螺线等极坐标图形，帮助理解角度、半径和对称性。

极坐标设置

-估计围成面积
-r 范围
θ → xy坐标变换

向量场与方向图

输入 P(x,y)、Q(x,y)，在平面网格上绘制方向箭头，快速观察源、汇、旋转场和梯度场。

向量场设置

-平均向量长度
-最大向量长度
归一化箭头便于观察方向

其他类型图表

除了数学曲线，还提供折线、柱状、饼图和散点图，用于数据展示、实验结果说明或报告嵌入。

数据图表设置

-总和
-平均值
-最大值
